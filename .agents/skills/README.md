# Project Skills

These project-local skills mirror the global Codex skills used for Codex Traffic Lights work.

## UI Redesign

- `frontend-design`: primary visual design workflow for polished UI direction.
- `liquid-glass-design`: optional glass/material reference for restrained translucent styling.
- `screenshot`: desktop screenshot capture for real visual verification.
- `ui-demo`: demo recording workflow after the UI is actually running.
- `imagegen`: optional bitmap mockups and asset generation.

## Delivery Workflow

- `tdd-workflow`: test-first checkpoints for product changes.
- `verification-loop`: final build, lint, test, coverage, and smoke verification.

Global copies remain in `%USERPROFILE%\.codex\skills`; these project copies make the same workflow
available from this repository's `.agents/skills` surface.
