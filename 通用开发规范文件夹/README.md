# 通用开发规范

> 本目录是项目开窗期与现代 AI 开发场景的规范入口。基础工程规范按顺序阅读；涉及 LLM API、RAG、Agent、多模型路由、MCP / Skills / Prompts 的项目，必须额外阅读 `06-AI产品专项规范.md`。

## 文件索引

| 文件 | 内容 |
|------|------|
| `01-启动决策清单.md` | 项目形态、技术栈、架构、工具链和依赖安全决策 |
| `02-项目脚手架模板.md` | 本地工具、库 / SDK、Web 全栈、API 服务、Monorepo、AI / LLM 应用目录模板 |
| `03-AI协作与上下文.md` | `CLAUDE.md` 模板、AI 助手启动检查、Skills、外部技能安装、多智能体协作和输出要求 |
| `04-初始文件与命名.md` | 开窗期初始文件清单、命名速查表、Git 协作命名 |
| `05-质量门禁与检查清单.md` | 代码规模控制、规范优先级、开窗期落地检查清单 |
| `06-AI产品专项规范.md` | Prompt / Model 版本化、eval、RAG、Agent、LLM 安全、成本、CC Switch 统一接入 |

## 使用方式

1. 新项目先读 `01-启动决策清单.md`，确定项目形态。
2. 按项目形态选择 `02-项目脚手架模板.md` 中的模板。
3. 创建 `CLAUDE.md` / `AGENTS.md` 时参考 `03-AI协作与上下文.md`。
4. 创建仓库基础文件和分支/提交规范时参考 `04-初始文件与命名.md`。
5. 提交前用 `05-质量门禁与检查清单.md` 做收口。
6. 任何 AI / LLM 项目额外执行 `06-AI产品专项规范.md` 的检查项。
