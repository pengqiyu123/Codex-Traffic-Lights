## 六、命名速查表

跨语言通用的命名约定（语言特有的见对应规则文件）：

| 类别 | 风格 | 示例 |
|------|------|------|
| 目录名 | `kebab-case` 或 `lowercase` | `user-profile/` 或 `userprofile/` |
| 常量 | `UPPER_SNAKE_CASE` | `MAX_RETRY_COUNT` |
| 布尔变量 | `is/has/can/should` 前缀 | `isLoading`, `hasPermission` |
| 类/类型 | `PascalCase` | `UserService`, `UserProfile` |
| 函数/方法 | 动词开头 | `getUserInfo`, `handleSubmit` |
| 测试文件 | `test_<name>` 或 `<name>.test.<ext>` | `test_workflow.py` / `Button.test.tsx` |
| 分支命名 | 类型前缀 + `kebab-case` | `feature/user-login`, `fix/pay-callback`, `release/v1.2.0` |
| Commit 消息 | Conventional Commits | `feat: 新增用户登录接口`, `fix: 修复订单精度问题` |

**布尔命名补充**：
- 避免反义布尔变量，例如 `isNotReady`、`hasNoAccess`。
- 优先使用正向命名：`isReady`、`hasAccess`，在使用处取反。
