# UI 设计方向：Codex Traffic Lights

> 基于 Anthropic `frontend-design` skill 的 anti-slop 设计哲学，适配 PyQt5 桌面悬浮组件场景。

## 设计思考

### Purpose
Windows 桌面悬浮状态指示器。程序员在 IDE/终端之间切换时，余光感知 Codex 工作状态。不需要切换窗口，不需要阅读文字——灯的颜色和节奏传达信息。

### Tone
**工业仪表 / 精密设备指示灯**

灵感来源：航空仪表盘 LED、录音台电平表、服务器机柜状态灯、DJ 台混音器指示灯。不是网页、不是 App、不是游戏 UI——是**硬件面板上的嵌入式指示器**。

### Constraints
- PyQt5 QPainter 自绘，无 Web 技术
- 尺寸受限：80x240px（compact）到 ~200x400px（expanded）
- 必须在 2 米外通过颜色+节奏识别状态
- 性能限制：空闲 < 1% CPU

### Differentiation
**让人记住的一件事**：灯光有真实的物理质感——玻璃罩、金属边框、内发光、外光晕，看起来像真正的硬件指示灯而不是屏幕上的圆形色块。

## 设计规范

### 色彩系统

不要用安全的灰色底+彩色圆。要像真正的精密设备一样有色调统一性。

```
底色系：#0D0D0F（近纯黑，微冷蓝调）
面板色：#16161A（略浅，区分层次）
边框色：#2A2A30（细金属灰边）
高亮边：#3A3A42（悬浮/激活态）

红灯系：
  亮色 #FF3B30 → 灭色 #2A0808 → 光晕 rgba(255,59,48,0.25)

黄灯系：
  亮色 #FFCC00 → 灭色 #2A2400 → 光晕 rgba(255,204,0,0.25)

绿灯系：
  亮色 #34C759 → 灭色 #082A10 → 光晕 rgba(52,199,89,0.25)
```

色彩原则：
- 灭灯不是灰色，是该色的极暗版本（保持色温一致）
- 光晕色与灯色同色系，低透明度扩散
- 底色是微冷蓝调的黑，不是纯中性黑

### 灯光质感

每个灯由以下层从下到上绘制：

1. **外壳凹槽**：深色圆形底（比背景更暗），模拟金属面板上的凹槽
2. **灭色填充**：灯的基础色（极暗版本），占据整个灯面
3. **亮色渐变填充**：从中心到边缘的径向渐变，中心更亮，边缘过渡到灭色
4. **高光点**：左上角小白点（模拟玻璃反射），固定位置不随动画变化
5. **内发光**：亮色半透明边缘光，模拟灯泡点亮时从内部照亮玻璃罩
6. **外光晕**：灯色径向渐变扩散到灯外，模拟光溢出效果（仅亮灯时启用）
7. **金属边框**：1px 细灰色描边，模拟金属环（仅 compact 模式，expanded 模式可省略）

### 灯直径与间距

| 模式 | 灯直径 | 间距 | 光晕半径 | 窗口尺寸 |
|------|--------|------|---------|---------|
| Compact | 36px | 12px | 6px | 72x220 |
| Expanded | 52px | 20px | 14px | ~200x400 |

### 动画原则

动画要像真实 LED 的物理行为，不是网页 CSS 动画：

- **呼吸（WORKING）**：模拟 PWM 调光的 LED，亮度在 25%-95% 之间平滑正弦变化。3 秒周期。不是网页 fade-in/fade-out，而是硬件呼吸灯的自然节奏。
- **闪烁（ERROR）**：快速但不刺眼，0.3 秒周期，亮度 20%-100%。像设备报错时的警告灯。
- **间歇闪（WAITING_USER_INPUT）**：0.5 秒亮→0.5 秒暗，像寻呼机提醒。
- **慢闪（WAITING_APPROVAL）**：2 秒周期，像等待确认的脉冲信号。
- **常亮（OFFLINE/IDLE）**：无动画，稳定发光。IDLE 的绿灯不显示光晕（低功耗待机状态）。

动画必须用 QEasingCurve.InOutSine 或类似平滑缓动，不用线性。

### 排版

- **标题文字 "CODEX"**：使用等宽字体（Consolas / JetBrains Mono / Source Code Pro），字重 Bold，字号 11px，颜色 #8A8A8F（低调的灰色，不抢灯光注意力）
- **状态文字**：使用同一等宽字体，字号 10px，颜色与当前灯色一致（红灯时红色文字，绿灯时绿色文字等）
- **按钮图标**：全部用 QPainter 绘制矢量图形，不使用 emoji。每个图标 24x24，线宽 1.5px，颜色 rgba(255,255,255,0.4)→hover rgba(255,255,255,0.9)

### 按钮设计

不用 emoji 文字按钮。改为矢量图标按钮：

| 按钮 | 图标绘制 | 样式 |
|------|---------|------|
| 通知 | 小铃铛轮廓 | 圆形底 + 铃铛 SVG path |
| 缩小 | 减号 | 圆形底 + 水平线 |
| 放大 | 加号 | 圆形底 + 十字 |
| 设置 | 齿轮 | 圆形底 + 齿轮 SVG path |
| 电源 | 圆圈+竖线 | IEC 电源符号 |
| 静音 | 扬声器+斜线 | 扬声器轮廓 + 对角线 |

常态：rgba(255,255,255,0.08) 圆形底 + 0.35 opacity 图标
Hover：rgba(255,255,255,0.15) 圆形底 + 0.9 opacity 图标 + 1px 边框
Pressed：rgba(255,255,255,0.22) 圆形底 + 1.0 opacity 图标
Active（checkable）：当前灯色的 0.15 底色 + 灯色图标

### Header 设计

不画云朵图标 + `_>_` 的粗糙方案。改为：

- **紧凑版本**：小矩形色块 + `>_` 终端符号（16x12px），`>_` 用 Consolas 8px，颜色 #56D7FF
- **CODEX 文字**：Consolas Bold 10px，字间距 +2px，颜色 #6A6A70
- 整体高度 50px（compact 模式），高度克制不抢空间

### 窗口形态

**Compact（默认）**：
- 72x220px 窄条
- 仅三灯 + 状态文字
- 贴边时仅露 8px 光晕边缘

**Expanded（点击展开）**：
- ~200x400px
- 显示会话列表（每个 Codex thread 一行：状态灯 + thread 名 + 状态文字）
- 全局状态灯在顶部，下方是 thread 列表
- 再次点击或 ESC 收回 compact

展开/收起用 QPropertyAnimation，200ms，InOutCubic 缓动。

### 多会话显示

当连接 app-server 且有多个 thread 时：

1. Compact 模式：显示全局最高优先级状态（ERROR > WAITING_APPROVAL > WAITING_USER_INPUT > WORKING > IDLE）
2. 状态文字显示：`待审批确认 · 2 会话`（状态 + 会话数）
3. Expanded 模式：列出每个 thread，每行一个 mini 状态点 + thread 名 + 状态

## 禁止事项（Anti-Slop）

- ❌ 不用 emoji 作为图标（🔔⏻🔇 等等）
- ❌ 不用纯灰色灭灯（必须保持色温一致的极暗版本）
- ❌ 不用扁平纯色圆形画灯（必须有层次质感）
- ❌ 不用线性缓动动画（必须用正弦/缓入缓出）
- ❌ 不用 Arial/system font 作为文字字体
- ❌ 不用白色高亮文字抢灯光注意力
- ❌ 不用网页模板式的 hover 效果（阴影+缩放）
- ❌ 不用默认的灰色 `#1A1A1A` 底色（改为微冷蓝调的 `#0D0D0F`）
