# Codex Traffic Lights 使用说明

## 启动

双击 `Codex Traffic Lights Portable.exe` 启动。

启动后会出现一个桌面悬浮红绿灯。它会自动读取 VSCode Codex 的状态，不需要额外配置。

## 状态含义

| 灯光 | 含义 |
|------|------|
| 绿灯常亮 | 空闲待命 |
| 黄灯慢呼吸 | 正在工作 |
| 黄灯闪烁 | 计划模式需要输入 |
| 黄灯 + 绿灯交替闪烁 | 待审批确认 |
| 红灯 + 黄灯快闪 | 运行异常 |
| 红灯常亮 | 离线休眠 |

## 常用操作

| 操作 | 说明 |
|------|------|
| 拖动窗口 | 移动位置 |
| 拖到屏幕左/右边缘 | 吸附到屏幕边缘 |
| 吸附后静置 3 秒 | 收缩为迷你灯条 |
| 鼠标移到迷你灯条上 | 临时展开 |
| 双击红绿灯 | 打开/关闭展开面板 |
| 齿轮按钮 | 打开/关闭声音设置 |
| 喇叭按钮 | 静音/取消静音 |

## 声音文件

默认声音放在程序旁边的 `sounds` 文件夹：

- `任务完成.mp3`
- `待审批确认.mp3`
- `计划模式输入.mp3`
- `运行异常.mp3`

在声音设置里点击“选择”后，程序会从 `sounds` 文件夹开始选文件。你也可以把自己的 MP3/WAV 放进这个文件夹，再到设置里选择。

## 更新版本

更新时建议先退出旧版本，再替换整个文件夹。

如果 Windows 提示无法覆盖 exe，说明程序还在运行。请先从托盘退出，或在任务管理器中结束 `Codex Traffic Lights Portable.exe`。

## 遇到问题

- 看不到窗口：检查任务栏托盘区域是否已有图标。
- 没有声音：确认没有静音，并检查 `sounds` 文件夹里的音频文件是否存在。
- 状态一直离线：确认 VSCode 和 Codex 插件正在运行。
- 测试多个版本时行为混乱：先退出所有旧窗口，再启动当前文件夹里的 exe。
